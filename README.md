# Assignment-03-isSorted-and-Sorting-Study

# Bubble Sort
+Best Case
Single pass, no swaps, and stops :=O(n)

+Average Case
Elements out of order, many swaps = 0(n^2)

+Worst Case
Every element has to be swapped to get a correct end =  0(n^2)

# Insertion Sort
+Best Case
Every element in correct position, only comparisons:=O(n)

+Average Case
Elements out of order, each element has to be shifted halfway back to the start= 0(n^2)

+Worst Case
Every element has to be shifted all the way back to the beginning. =  0(n^2)


# QuickSort

+Best Case
Picks middle element as pivot, split in half to sort data = O(n log (n))

+Average Case
Random data in equal halves= O(n log (n))

+Worst Case
None observed, but it still does the same as before even if reversed =  O(n^2)

Selection Sort
+Best Case
data sorted, still has to scan every unsorted element to find the min. =O(n^2)

+Average Case
Same amount of comparisons, doesn’t care about order= 0(n^2)

+Worst Case
Same amount of scans =  0(n^2)
